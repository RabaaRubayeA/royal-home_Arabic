# royal-home_Arabic
🛋️ نموذج أولي لصفحة هبوط تفاعلية (MVP) مخصصة لمعرض "رويال هوم للأثاث" في اليمن. تم بناؤها باستخدام HTML, CSS, و Vanilla JS لاستعراض المنتجات وتسهيل الطلب عبر الواتساب.
# 🛋️ رويال هوم للأثاث - صفحة هبوط تفاعلية (Landing Page MVP)

صفحة هبوط احترافية متكاملة (Single Page Application) تم تصميمها وتطويرها كنموذج أولي (MVP) مخصص لـ **معرض رويال هوم للأثاث وغرف النوم** في اليمن. تهدف الصفحة إلى نقل تجربة عرض المنتجات من شبكات التواصل الاجتماعي التقليدية إلى بيئة ويب مخصصة وتفاعلية تعكس فخامة الهوية البصرية للمعرض وتزيد من معدل تحويل الزوار إلى عملاء حقيقيين.

---

## 🚀 ميزات المشروع (Key Features)

* **تصميم ملكي فاخر (Premium UI):** استخدام ألوان متناسقة (الأسود الفاخر والذهبي الملكي) تعكس طبيعة المنتجات الكلاسيكية والمودرن المعروضة.
* **كتالوج منتجات تفاعلي (Interactive Tabbed Catalog):** إمكانية التنقل السلس بين تصنيفات الأثاث (غرف نوم، أطقم كنب) في نفس الصفحة بدون الحاجة لإعادة التحميل بفضل الجافاسكربت.
* **تجربة مستخدم متجاوبة (Fully Responsive):** متوافق تماماً مع جميع الشاشات (الهواتف الذكية، الأجهزة اللوحية، والشاشات المكتبية).
* **ربط مباشر ومخصص بالواتساب (Smart WhatsApp CTA):** أزرار تفاعلية مربوطة بالرقم الرسمي للمعرض مع رسائل مجهزة مسبقاً تلقائياً لتسهيل استفسارات الزبائن وحجوزاتهم.
* **أقسام تسويقية متكاملة:** يتضمن المشروع أقساماً خاصة بالميزات التنافسية، الباقات وعروض العرسان، آراء العملاء لبناء المصداقية، وتفاصيل الفروع الجغرافية.

---

## 🛠️ التقنيات المستخدمة (Technologies Used)

* **HTML5:** لبناء الهيكل البنائي والمنطقي للصفحة بشكل متوافق مع معايير الـ SEO.
* **CSS3:** لتصميم الواجهات، إدارة المصفوفات التجاوبية (Flexbox & CSS Grid)، وإضافة تأثيرات الحركات والنبض (Animations & Hover Effects).
* **Vanilla JavaScript (ES6 Modules):** للتحكم في منطق التنقل بين التبويبات وعرض المنتجات بسلاسة وخفة متناهية.
